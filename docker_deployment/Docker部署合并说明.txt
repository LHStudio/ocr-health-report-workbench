Docker 服务器合并说明
====================

这个压缩包不包含模型权重，也不替换对方已经配置好的 Docker、镜像、依赖或模型下载方式。

压缩包内文件：

1. app.py
   当前增强版 OCR API，已兼容 Docker 环境。它新增：姓名增强识别、食物频率问卷勾选识别、/classic-ocr、耗时统计、结构化返回等。
   Docker 原始调用地址 http://172.18.0.2:8118/v1 已保留为注释；Docker 环境可通过 PADDLEOCR_VL_SERVER_URL 环境变量继续使用该地址。

2. questionnaire_templates/food_frequency_blank_reference.png
   增强版第 1 页就餐地点勾选识别必需的空白参考模板。

3. questionnaire_templates/food_frequency_sunlight_blank_reference.png
   增强版第 3 页日照时段、皮肤暴露部位勾选识别必需的参考模板。
   两个模板都需复制到 app.py 同级目录下的 questionnaire_templates/ 目录。

4. docker_ocr_service.sh
   可选的一键管理脚本，适用于对方使用 docker compose 的情况：start / status / restart / logs / stop。
   如果对方已有自己的 Docker 启动方式，可以不使用它。

合并步骤：

1. 先备份对方容器或挂载目录中的 app.py。
2. 将压缩包内 app.py 替换为运行位置的 app.py。
3. 放入 questionnaire_templates/ 下的两个 PNG 模板文件。
4. 保持对方原 Docker 的模型地址。若其原版就是 172.18.0.2:8118，则可设置：
   PADDLEOCR_VL_SERVER_URL=http://172.18.0.2:8118/v1
   OCR_SERVICE_BASE_DIR=/app/pdf_to_excel_service
5. 重建/重启原有 API 容器，并调用 GET / 检查返回 status=ok。

注意：不要把当前裸机服务器的 /root/start_ocr_stack.sh 复制到 Docker 服务器。
