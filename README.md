# OCR 健康报告工作台

本仓库按运行环境拆成两个相互独立的目录，避免把 Windows 本地业务程序、Linux GPU OCR 服务和历史备份混在一起。

## 目录说明

| 目录 | 用途 | 运行位置 |
| --- | --- | --- |
| [`当前项目`](./当前项目/README.md) | Vue 前端、本地 FastAPI 后端、营养报告、模板和自动化测试 | Windows 工作电脑 |
| [`服务器配置`](./服务器配置/README.md) | PaddleOCR-VL、OpenCV 图像增强、OCR API 和启停脚本 | Linux GPU 服务器 |

本地工作台通过 HTTP/HTTPS 调用 GPU 服务器的 OCR API。两部分可以独立安装和更新，详细操作分别见各自目录中的 README。

## 不进入仓库的内容

以下内容只保留在本地，不会上传到 GitHub：

- 原始体检、影像和问卷资料；
- OCR 任务数据、导出报告和运行日志；
- 历史版本、弃用程序和可再生成文件；
- 服务器备份、模型权重、部署压缩包；
- 密码、令牌、私有环境变量及其它敏感配置。
